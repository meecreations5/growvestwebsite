# GrowVest Motion Update v7

## Brand icon

- Removed the multi-colour animation.
- All animated GrowVest marks now use the single GrowVest cyan brand colour (`#18B7D3`).
- Retained a restrained upward-arrow movement and soft glow for continuity.
- The header still changes from the long wordmark to the compact icon after scrolling.

## Homepage hero

- The large decorative GrowVest symbol is now outline-only rather than filled.
- The outline uses the GrowVest cyan brand colour with restrained opacity.
- Existing entrance and desktop parallax behaviour remain available.

## Buttons

- Removed magnetic movement and tactile press scaling.
- Added a mouse-follow spotlight, a single light-sweep effect and a gentle arrow/icon glide.
- Touch devices receive the normal static button experience.

## Page transitions

- Added a calm App Router page-entry transition using fade, slight rise and brief blur removal.
- The fixed header and footer remain stable while page content changes.
- All motion is disabled when the visitor prefers reduced motion.
