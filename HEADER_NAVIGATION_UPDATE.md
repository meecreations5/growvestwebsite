## Interaction correction

The delayed close action now closes only the dropdown that originally scheduled it. Moving the pointer directly from one top-level menu to another therefore cannot allow the previous menu's timer to close the newly opened submenu. The hover bridge remains part of the dropdown wrapper, and the close delay is 220 ms for easier pointer movement.
