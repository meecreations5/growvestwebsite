# Firebase Storage rules — GrowVest Website Media

Website media is uploaded by Firebase Admin through protected server routes. Public browser uploads are not required.

Merge the policy carefully with any existing Investor Portal Storage rules. A restrictive website-media rule is:

```rules
match /website-media/{allPaths=**} {
  allow read, write: if false;
}
```

Published media uses tokenised Firebase download URLs generated by the server. Do not expose Firebase Admin credentials in browser code.
