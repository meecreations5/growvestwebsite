# GrowVest v22.5 — Investor Testimonial Design Update

The Investor Experiences section has been redesigned to match GrowVest's premium editorial visual language.

## Improvements

- Replaced the oversized dark testimonial panel with a clean, premium editorial layout.
- Added a restrained blue-to-gold accent rail instead of a heavy full-card brand fill.
- Improved visual hierarchy for the section heading, investor identity, journey type and quote.
- Added verified-consent treatment without implying investment-performance verification.
- Added refined supporting cards with consistent spacing and typography.
- Added mobile horizontal scroll with snap alignment for supporting testimonials.
- Reduced section height and improved the transition into the Insights library.
- Preserved the required testimonial disclosure.
